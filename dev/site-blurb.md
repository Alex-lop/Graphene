**Graphene**

See your coding agents' plan and change it before any code.

October 2026. Python 3.12+, Typer, Rich, Textual, SQLite, git. Apache-2.0.

Ok, so the idea is pretty simple. Before an agent writes anything in your repo, it shows you what it
understood: a plan as a tree, every piece with the files it may touch and the check that proves it's
done, plus the questions it couldn't answer, each with a default. You fix the plan in the terminal,
then Claude Code, Codex or Nemotron run the pieces side by side, and git holds each one to its plan.
There's a meter now too, so you see the agents' minutes and dollars right next to yours. Still early,
honestly.
