# A 75-second video from `graphene demo --cheat` and `graphene demo`

Everything is filmed from commands anyone can run for free. Narrate in the first person; do not narrate the
replay's dollars (a stand-in's prices). Record from the released wheel so the words match.

1. **0 to 8 s.** An empty terminal. Type `graphene demo --cheat`. SAY: "A script is going to play a coding agent that
   tries to cheat. No model runs. The locks are the real ones."
2. **8 to 40 s.** The seven moves scroll up. Pause on 1, 3 and 7. SAY: "It writes a file outside its task: refused
   before the write. It writes the file from a script: the hook can't see that, git catches it at done. It edits the
   test its own check runs: Graphene flags it, because it cannot know whether the change was right."
3. **40 to 50 s.** The closing lines. SAY: "Six refused, one flagged, none through. And it says what it does not show:
   a script played the agent; a real model will try other things."
4. **50 to 70 s.** Type `graphene demo`. Step to the leaf that came back ("the word lives in words.py", widen).
   SAY: "Here is the plan first. This leaf needed a file I took away. It didn't touch it; it came back with the reason."
5. **70 to 75 s.** The README's try-it line on screen. SAY: "One command, no key. I'd like to know where the plan
   misread you."
