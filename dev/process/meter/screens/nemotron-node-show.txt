xml-read (revision 1): XML reader
  why:    Load Northwind's XML price feed through the existing `load` command with `--source xml`, producing the same JSONL records as csv and json.
            Read the XML feed (xml-reader)
  goal:   Add `read_xml` in a new `ingest/xmlfeed.py` and register it in `READERS` in `ingest/__init__.py`. It returns one dict per `<product>` element, in feed order, using the attributes `code`, `desc` and `price`. Other elements such as `<summary>` are ignored, so the day-total line never becomes a record. Entities and Unicode come through as written, because the XML parser decodes them. Empty or whitespace-only text returns `[]` instead of raising. A product missing an attribute simply lacks that key, and `normalize` already turns that into a skipped record. The test file covers the summary line, `&amp;`, accents and Chinese, order, empty input, and a product missing each attribute.
