# dev

This folder is how Graphene gets built: the decisions, the directives and the morning briefs, the experiments and
their harness, the proofs, the screens, and the demo's build.
You don't need any of it to use Graphene. The docs for using it are in [docs/](../docs/).

An agent starts from [VISION.md](VISION.md) (the direction), [SCOPE.md](SCOPE.md) (the job), and
[prompts/workflow.md](prompts/workflow.md) (the prompt). The look to reach is [ui/canvas.html](ui/canvas.html).
[DIRECTION.md](DIRECTION.md) is the decision log, not the brief.
