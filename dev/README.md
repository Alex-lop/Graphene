# dev

This folder is how Graphene gets built: the decisions, the directives and the morning briefs, the experiments and
their harness, the proofs, the screens, and the demo's build.
You don't need any of it to use Graphene. The docs for using it are in [docs/](../docs/).

An agent starts from [SCOPE.md](SCOPE.md), [PRODUCT_NEXT.md](PRODUCT_NEXT.md), and
[prompts/workflow.md](prompts/workflow.md). [WORKFLOW_IDEAS.md](WORKFLOW_IDEAS.md) is the workflow
direction those three carry. [DIRECTION.md](DIRECTION.md) is the decision log, not the brief.
