## The question

From the terminal directive, section 7: *count what the product claims to save: person-seconds
from the paragraph to the run, keystrokes, and misunderstandings caught before code (proposal
items the person removed or changed that would have cost a restart). Report it the way the first
two were reported, without flattering the tool.*

The product being tested is the directive's reframe: **paragraph in, tree out, prune, run.** The
person types a paragraph, the agent proposes a tree, and the person reads it, prunes it and runs
it. The claim is that reading and pruning is cheap, and that it catches a misunderstanding before
any tokens are spent on it.

## What changed since 21 September

- **The tree arm replaces the graphene arm.** The person no longer authors nodes. They type a
  paragraph to a session in the repository, the repository's hooks make that session propose a
  tree, and the person prunes it. Pruning uses only the commands the `graphene watch` keys run:
  `plan accept` (y), `node drop` (d), `node set` or a text edit through `plan edit` (e, E),
  `run --parallel 4` (R), and `node widen|sibling|reopen` (w, b, x) for a leaf that comes back.
  `standin.py` prints both briefs from one template. Diffing them shows they differ only in the
  arm section.
- **New measures, from `attention.py`:**
  - **Typed characters.** For a text edit, only the characters the saved text added are counted,
    by character diff.
  - **Acts:** every person entry except a `read`.
  - **Words read:** everything the person was shown and logged as `read` (replies, the tree,
    diffs, files, command output).
  - **Modelled person-seconds**, for the whole run and up to the first run.
  - **The nodes changed before the first `started`**, each with its contract as proposed, for a
    judge.
- **The keystroke-level model** (Card, Moran & Newell, 1980):
  - K = 0.28 s per typed character. This is the model's figure for an average non-secretarial
    typist, about 40 words a minute.
  - M = 1.35 s of mental preparation per act.
  - Reading at 250 words a minute (0.24 s a word) for every word logged as read. Reading is not
    part of the original model; the spec added it.
  - **Person-seconds in this report are that model, never a clock.** Every table that shows them
    shows the three parts beside them.
- **`newrun.sh` writes `env.sh`.** Every shell of a run sources it first. It pins the build's `bin`
  first on `PATH`, which was the failure that voided a run on 21 September. It defines:
  - `as_me`, which strips all six agent marks;
  - `did`, which runs a command, logs it as an act and logs its output as read, and refuses to run
    an act it cannot log;
  - `seen`, which runs a command and logs its output as read;
  - `reply`, which logs an executor's reply as read.
- **`logline.py` has new types:** `drop`, `edit`, `widen`, `sibling`, `reopen` and `read`, plus
  `--edit before after`.
- **`tally.py` has three changes:**
  - A `read` is not an act.
  - A `reopen` counts as a restart.
  - **Cost is counted once per executor session.** The last change is a fix, found while tallying
    this test, that also changes the 21 September numbers (see "A correction to the 21 September
    report").
- **Tests:** `test_tally.py` has a fixture for the cost fix, and `test_attention.py` adds 7 tests
  whose sums are worked by hand. All 27 pass.
- **`summarize.py` reads the tree arm and prints the attention columns.** Its default output file
  is now `runs-2026-09-23.json`. That protects the 21 September record, but it means a bare
  `summarize.py <dir>` now writes over this one. `PROTOCOL.md`'s recipe passes `--out`.

## What the numbers do not show

- **They do not measure a person.** Every "person" is a language model with the card in its
  context. Person-seconds are the keystroke-level model with a reading rate added. The model:
  - assumes an error-free typist at about 40 words a minute and 1.35 s of thought per act;
  - does not count the time it takes to *compose* a 3600-character paragraph, which is most of
    the real cost;
  - assumes every word shown was read at 250 words a minute, where a person skims a diff and
    re-reads nothing they already know.
