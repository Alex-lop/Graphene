# Three pictures for the README, as prompts

`loop-ink.svg` and `loop-ivory.svg` beside this file are a hand-drawn stand-in for the first; the prompts below make
all three in the brand's own palette, for an image model or an illustrator. Every number and word in them is one the
screens print.

**The style, shared by all three.** Flat vector illustration, two colours only: ink `#141413` on ivory `#F0EEE6`, and a
second version with ivory on ink. Monospace labels. Thin 2px strokes, no gradients, no shadows, no 3D, generous
margins, 16:9. The motif is Graphene's mark: a small tree whose one branch is pruned with a short stroke
(`docs/brand/mark/`). Nothing decorative that a label does not need.

## 1. The loop

Three nodes in a row. On the left a person at a terminal, labelled `you`. In the middle a small tree of five nodes
labelled `the plan`, one node marked with a check, one branch pruned. On the right two agents drawn as plain
terminals, labelled `your agents`. Arrows: from you to the plan, `accept, prune, run`; from the agents to the plan,
`propose, do, done`; from the plan back to you, `what landed, what it cost`; from the plan to the agents, `a task:
its files, its check`. Each label fits between the two boxes in a browser (checked in Chrome). Along the plan's lower edge four short labels: `scope: refused before the write`, `check: run by
Graphene in a clean worktree`, `red first: a check that already passes is flagged`, `done: git says what changed`.
Caption: `You shape the plan. Your agents work inside it. Graphene holds the edges.`

## 2. The first hour

A horizontal timeline of seven stops, each a monospace command under a small icon: `uv tool install graphene-map`
(a box), `graphene demo` (a play mark), `graphene init` (a hook), `graphene ask` (a speech bubble with a paragraph),
`graphene watch` (the tree with `y` and `d` beside it), `graphene run` (two lanes merging into one line), `graphene
node show` (a page). A thin clock line underneath reads `an hour, your first`. No arrows between the stops; the line
is the order.

## 3. Held, not promised

Two columns. Left, headed `the agent promises`: one speech bubble saying `I only touched src/`. Right, headed
`Graphene holds`: four stacked plates, each one line, `the hook refuses a write outside the scope`, `the check runs in
a clean worktree`, `red first: a check that already passes is flagged`, `done: git lists what changed`. A small pruned
tree in the lower corner. The left column has more white space than the right: the promise is one line, the holds
are four.
